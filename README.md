# TubeToViral (YouTube 爆款视频转 X/LinkedIn 资产包一键生成工具)

> **极简输入，爆款交付。** 专为 Solo 创作者、出海团队与 B2B 创始人量身打造的单页内容资产分发工具。

---

## 💡 产品定位与核心思考

### 为什么不做通用 AI 写作器？
市面上的通用 AI 写作器（ChatGPT、Claude 客户端等）遍地都是，但最大的痛点是：
1. **输入成本过高：** 用户面对空荡荡的输入框，根本不知道该如何编写 Prompt。
2. **内容空洞乏味：** 缺乏真实、高密度的事实来源，极易生成充斥套话与 AI 口癖的垃圾内容。
3. **分发格式割裂：** 纯文本长文无法直接用于社交媒体，仍需创作者花费大量时间手动改写排版。

### TubeToViral 的解决方案：
- **极简单一输入：** 仅需粘贴 1 个高赞 YouTube 视频链接（深度播客、技术讲座、商业访谈）。
- **三合一高价值交付包：**
  1. **1 篇 X (Twitter) 爆款 Thread：** 包含 98+ 高 CTR 黄金 Hook、7 篇递进拆解、反共识论点、闭环 CTA。
  2. **1 篇 LinkedIn 深度专业复盘长文：** 领袖管理层口吻、痛点切入、职业排版规范与精准 Hashtags。
  3. **5 条精炼金句 / 日常排期短推文：** 提炼核心金句，按周一到周五排期规格封装，无缝导入 Buffer / Hypefury。

## 💰 商业模式与变现闭环

1. **免费尝鲜 (Hook 体验)：**
   - 默认赠送 1 次完整高价值体验额度。
   - 额度用完后，可继续免费生成前 **30% 精彩内容预览**（Hook 首推 + 前两点可见），后 70% 内容通过高端毛玻璃（Frosted Glass）虚化锁定，形成强烈的“损失厌恶”冲动。
2. **冲动买断 Pack 模式 ($9 / 50 次额度)：**
   - 单视频成本仅 **$0.18**，没有每月自动扣费的心理压力，极其契合海外 Solo 创作者与独立开发者的冲动消费习惯。
3. **Pro Unlimited 会员 ($19 / 月)：**
   - 针对重度内容营销机构、出海矩阵博主，享受无限次转录与 GPU 优先通道。
4. **Stripe 级结账收银台：**
   - 支持 Pay、Google Pay 与信用卡极速一键模拟支付，支付完成自动触发全屏礼花（Confetti）并瞬间解锁全量资产。

## 🛠️ 技术实现与架构

- **前端架构：** 纯原生 HTML5 + 现代化 Vanilla CSS + ES Modules，零冗余依赖，极致毫秒级加载速度。
- **视觉设计规范：**
  - **主题基调：** 曜石暗黑（Obsidian Dark）+ 赛博电光紫（#8b5cf6）+ 霓虹青蓝（#06b6d4）高质感渐变。
  - **拟真社交预览：** 真实还原 X (Twitter) 连推连接线仿真器与 LinkedIn 领袖动态排版。
  - **字体：** Google Fonts (`Plus Jakarta Sans` 与 `JetBrains Mono`)。
- **预载经典视频体验包：**
  - Naval Ravikant: 如何不靠运气致富
  - Sam Altman (YC): 创造未来与 AGI 战术手册
  - 黄仁勋 (NVIDIA): 苦难、韧性与万亿帝国
  - Andrew Huberman: 多巴胺、专注力与巅峰生产力
- **动态解析能力：** 支持任意新粘贴的 YouTube 链接，自动调用 YouTube oEmbed 接口解析封面、标题与作者，并智能合成分发资产包。

## 🚀 本地启动方式

你可以使用任意静态文件服务器运行本应用：

```bash
# 方式 1: 使用 Python
python -m http.server 3000

# 方式 2: 使用 Node.js npx serve
npx serve -p 3000 .
```

打开浏览器访问 `http://localhost:3000` 即可开始使用。
